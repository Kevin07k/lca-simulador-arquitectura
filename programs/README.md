# Programas de demostración / Demo programs

Guardar aquí los programas ensamblador de P15–P17 y sus datos iniciales. Se crearán cuando estén disponibles el ensamblador y el cargador. No hay programas ejecutables en P03.

English: assembly demos and initial data for P15–P17 belong here. They will be added after the assembler and loader exist. P03 includes no executable demo program.
